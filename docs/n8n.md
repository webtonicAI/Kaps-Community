# Kaps + n8n

The n8n automation guide now lives in the Kaps app. Sign up (or sign in) to create an API key and follow the walkthrough:

**[kaps.ai → Info → n8n](https://kaps.ai/info?doc=n8n)**

You will need a Kaps account at [kaps.ai](https://kaps.ai). Free-tier renders include the Kaps watermark.

Quick facts:

- **API base URL:** `https://api.kaps.ai/functions/v1`
- **Auth:** `Authorization: Bearer ksk_live_...`
- Create keys in Studio → **API**
