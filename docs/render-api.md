# Kaps Render API

The full REST API reference — auth, all endpoints, webhooks, pricing, and code examples — now lives in the Kaps app:

**[kaps.ai → Info → API Reference](https://kaps.ai/info?doc=api)**

Quick facts:

- **Base URL:** `https://api.kaps.ai/functions/v1`
- **Auth:** `Authorization: Bearer ksk_live_...` (or `X-API-Key: ksk_live_...`)
- Create/manage keys in Studio → **API**

For the MCP wrapper, see [MCP server](./mcp.html). For n8n, sign in at [kaps.ai → Info → n8n](https://kaps.ai/info?doc=n8n).
