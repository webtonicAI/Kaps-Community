# Kaps Community

**[Kaps](https://kaps.ai)** is a futuristic caption maker: AI categorises your text, and a sophisticated UI for creating custom captions. This site is the community — help, guides, and discussion.

Full API, MCP, n8n, and performance docs now live in the Kaps app itself (Studio → **API** / **Info**). Sign up at [kaps.ai](https://kaps.ai) to create an API key. This site keeps short pointers:

- [n8n](n8n.html) — pointer to the in-app n8n guide
- [MCP server](mcp.html) — install & configure `@kaps_ai/mcp-server` for Claude, Cursor, and other MCP clients
- [Render API](render-api.html) — quick reference, links to the full docs
- [Performance help & FAQ](performance-help-and-faq.html) — quick fix, links to the full FAQ
- [Legal](legal/) — privacy policy and terms of service
- [Issues on GitHub](https://github.com/webtonicAI/Kaps-Community/issues) — bugs, ideas, and discussion

A [documentation file index](https://github.com/webtonicAI/Kaps-Community/blob/main/docs/README.md) is available in the repository.
